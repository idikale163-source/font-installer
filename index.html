🎨 字体站一键部署

填入你的平台凭证，自动搭建完全属于你的私有字体站
⚠️ 使用前须知
本页面只做"调用各平台 API"的转发，不会保存你的任何 Token（全部在你的浏览器里直接请求）。 但请确认你信任本页面的提供者。

1GitHub 配置

需要 repo 权限（创建/读写仓库）
生成地址：github.com/settings/tokens
用英文，建议 my-fonts

2Vercel 配置

生成地址：vercel.com/account/tokens
⚠️ 请先在 Vercel 里用 GitHub 登录一次，授权它访问你的仓库

3域名配置

最终访问地址将是：fonts.example.com

🎉 部署完成！

首次访问可能需要 1-3 分钟等待 DNS / SSL 生效
打开我的字体站 →

⚠️ 还差最后一步：手动添加 DNS

去 Cloudflare → 你的域名 → DNS → 添加记录，填入下面参数：
类型：CNAME
名称：-
内容：cname.vercel-dns.com
代理状态：☁️ 已代理（橙云） ← 必须开！

📖 遇到问题？

· Token 无效 → 检查是否有空格，重新复制
· 找不到域名 → 确认域名已接入 CF，且 Token 有 Zone:Read 权限
· 部署失败 → 确认 Vercel 已授权你的 GitHub
· 打不开网站 → 等 3 分钟，清了缓存再试
