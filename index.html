本页面只做"调用各平台 API"的转发，不会保存你的任何 Token（全部在你的浏览器里直接请求）。 但请确认你信任本页面的提供者。

1GitHub 配置

需要 repo 权限（创建/读写仓库）
生成地址：github.com/settings/tokens
用英文，建议 my-fonts

2Vercel 配置

生成地址：vercel.com/account/tokens
⚠️ 请先在 Vercel 里用 GitHub 登录一次，授权它访问你的仓库

3Cloudflare 配置

需要权限：Zone → DNS → Edit，以及 Zone → Zone → Read
生成地址：dash.cloudflare.com/profile/api-tokens
⚠️ 你的域名必须已经接入 Cloudflare（NS 已改）

4域名配置

最终访问地址将是：fonts.example.com
